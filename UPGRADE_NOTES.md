# NEUROPIX 2.0 — пакет первого этапа

## Изменения
- Удаляется публичный `GET /tasks/{task_id}`, который позволял проверять задачи GEN202 без авторизации.
- `Idempotence-Key` ЮKassa становится детерминированным по номеру заказа и способу оплаты.
- `.env.example` дополняется всеми переменными окружения, используемыми текущим кодом.

Скрипт проверяет все исходные фрагменты до записи, создаёт резервные копии и прекращает работу, если код отличается от ожидаемого. Это намеренно консервативный патч.

## Пока не реализовано
- Дедупликация вебхуков MAX: сначала требуется подтвердить фактическое поле ID события в payload MAX.
- Восстановление `submission_unknown`: нельзя повторно создавать задачу, пока не подтверждён безопасный способ найти уже принятую задачу в GEN202.
- Фоновая проверка задач и автоматическая отправка готовых медиа в MAX.
- Полные интеграционные тесты MAX, YooKassa и GEN202.

## Применение
1. Распаковать содержимое ZIP в корень локальной копии репозитория.
2. Выполнить `python apply_neuropix_2.py`.
3. Проверить `git diff`.
4. Выполнить `python -m compileall main.py gen202.py yookassa.py`.
5. Выполнить `python -m unittest discover -s tests`.
6. После проверки загрузить изменения только в ветку `neuropix-2.0`.

Не запускать в `main`. Не устанавливать `ENABLE_PAID_GENERATION=true`. Не проводить реальные платежи и платные запросы GEN202.

## Откат
Вернуть исходные файлы из каталога `.neuropix-backup-YYYYMMDD-HHMMSS`, созданного скриптом.
